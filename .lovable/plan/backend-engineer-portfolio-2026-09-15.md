# Backend Engineer Portfolio

## Build
- Create one structured portfolio data file containing personal details, navigation, skills, projects, certifications, social links, and contact copy.
- Build a single-page portfolio that renders every section from that data, with a sticky scroll-aware navigation bar and mobile menu.
- Add the requested hero, NestJS code panel, engineering philosophy, skill matrix, project cards, certifications, contact form, and footer.

## Experience
- Establish the specified warm light design system with indigo accents, Plus Jakarta Sans typography, high contrast, compact cards, and restrained shadows.
- Add accessible labels, keyboard focus rings, 44px touch targets, semantic landmarks, skip navigation, and clear form feedback.
- Add scroll entrance and code-line reveal motion with reduced-motion fallbacks, without introducing layout shifts.

## Contact behavior
- Validate name, email, and message while typing and on submission.
- Show explicit success or error toast feedback; successful submission opens the visitor's email client because no backend is requested.

## Static delivery and verification
- Configure the home route for static prerendering suitable for GitHub Pages and add portfolio-specific metadata.
- Verify desktop and mobile rendering, navigation, interactions, validation, and reduced-motion behavior in the live preview.
